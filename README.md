# Chanukya Rakshasa — Helping & Reporting Portal

**Chanukya Rakshasa** is a web-based helping and reporting portal designed to provide citizens, students, women, children, and other users with easy access to information, reporting resources, safety guidance, and awareness content.

The project focuses on creating a simple, accessible, and informative platform where users can learn about their rights, access safety information, understand reporting procedures, and find useful resources.

---

## 📌 Project Overview

Chanukya Rakshasa aims to bridge the gap between citizens and useful safety, awareness, and reporting information through a user-friendly web interface.

The portal provides different sections covering:

* Citizen awareness
* Complaint/reporting guidance
* Women and children safety
* Student awareness
* Cyber safety
* Health and safety information
* Environmental awareness
* Frequently asked questions
* Safety tips
* Daily awareness information
* Citizen/user manuals
* Privacy and policy information

---

## 🎯 Objectives

The main objectives of the Chanukya Rakshasa project are:

1. To provide citizens with easily accessible safety and awareness information.
2. To educate users about their basic rights and available reporting procedures.
3. To provide guidance for reporting different types of issues.
4. To create awareness about cyber safety and responsible digital usage.
5. To provide useful information for students, women, and children.
6. To encourage citizens to become more aware of social and environmental issues.
7. To develop a simple and user-friendly web platform for public awareness.

## 🚀 Getting Started

Because the project contains web pages, it can be run locally using a web browser.

### Method 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Locate `index.html`.
4. Double-click `index.html`.
5. The website will open in your default browser.

### Method 2 — Using a Local Server

You can also run the project through a local development server such as XAMPP, VS Code Live Server, or another HTTP server.

Place the project inside the appropriate web-server directory and open the local server URL in your browser.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/chanukya-rakshasa.git
```

## 🔒 Privacy & Security

The project is intended as an awareness and information platform.

When deploying the project publicly:

* Do not publish passwords or API keys.
* Do not upload private user information.
* Do not include real complaint records containing personal information.
* Do not expose database credentials.
* Review administrator credentials before deployment.
* Keep sensitive configuration files outside the public repository.

## ⚠️ Disclaimer

Chanukya Rakshasa is an educational and awareness-oriented project.

The information provided through the portal should not be considered a substitute for official government, legal, medical, police, or emergency services.

For serious or urgent situations, users should contact the appropriate official authority or emergency service.
